Rules

Board size is 15×15. Black moves first. The game ends when either color has five consecutive stones horizontally, vertically, or diagonally. Optional Renju-style forbidden-move rules prevent Black from playing double-three, double-four, or overline.

About

Originally developed by Kai as a college Java programming project in 2009. Ported to the web in 2026.
